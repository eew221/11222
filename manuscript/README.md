The source refers to a qualitative figure derived from the restricted underlying image collection. That source image and the compiled PDF are intentionally not included in this public repository until the data owner confirms publication and redistribution permission. A fully clean-room rebuild of the qualitative figure requires authorized local data access.

The non-image analysis figures can be regenerated with the analysis and plotting scripts after the authorized data, manifests, checkpoints, and prediction caches have been placed at the paths configured for the local run.
