# Figure availability

The repository includes non-sensitive aggregate figures needed to inspect the protocol and reported summaries:

- `v23/fig1_rc_wssi_pipeline.pdf`
- `v23/fig2_risk_coverage.pdf`
- `v23/fig3_calibration_feasibility.pdf`
- `v23/fig4_assignment_contamination.pdf`
- `v23/fig6_selected_allocation_pairs.png`
- `v23/fig7_human_reference_assignment_audit.pdf`

It intentionally excludes `fig5_real_qualitative.pdf`, which contains qualitative material derived from the restricted construction-image source. When that file is absent, the manuscript source builds with a clearly labeled placeholder; the authorized local submission build uses the manually redacted figure. The public aggregate figures do not contain source images.
