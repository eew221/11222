# v0.4.4

This final archival release accompanies manuscript v38, *Geometry-Defined
Single-Owner PPE Evidence Allocation and Cross-Worker Contamination Analysis*.

It freezes the 38-reference manuscript source, public non-image analysis
artifacts, audit protocols, reproducibility documentation, and MIT-licensed
experiment code. The release deliberately excludes original construction-scene
images, per-image labels, detector weights, prediction caches, and
image-derived overlays because they remain subject to confidentiality and
privacy controls.

The immutable GitHub tag identifies the exact archived commit. Zenodo creates a
version-specific DOI for this release under concept DOI
`10.5281/zenodo.22119277`.
