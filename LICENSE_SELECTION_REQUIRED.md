# Code license selection required

No open-source license has been selected for this repository yet. Until an actual `LICENSE` file is added by the code copyright holder, standard copyright applies and third parties do not receive broad permission to reuse, modify, or redistribute the code.

Before public release, the authors should:

1. Confirm which files are original project code and which contain third-party code or copied fragments.
2. Select a compatible license for original code, for example MIT, BSD-3-Clause, Apache-2.0, or GPL-3.0-only, based on the intended reuse terms and institutional policy.
3. Add the exact license text to a root `LICENSE` file.
4. Record third-party software and dataset licenses separately. An open-source code license does not grant rights to the PPE images, model weights, or annotations.
