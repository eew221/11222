# RC-WSSI v0.4.1

Release tag: `v0.4.1`

This submission-preparation release supersedes `v0.4.0`. It adds the MIT
license, Zenodo metadata, final v30 manuscript source, and aggregate results
for the pre-frozen source-stratified random open-candidate human ownership
audit.

## Included

- `manuscript/main_v30.tex` and non-sensitive figures used by the source.
- Open-candidate random-audit preparation, serving, analysis, and scoring code.
- Aggregate random-audit manifests, method summaries, and paired differences.
- MIT license for original project code and `.zenodo.json` archival metadata.

## Audit summary

The random audit contains 66 images from 11 filename groups and 334 PPE boxes.
Three blinded passes yield 321 determinate owner rows after excluding 13
ambiguous rows. RC-WSSI matches 320/321 determinate human owner sets. These
results are sampled ownership evidence only, not full-corpus truth,
cluster-valid inference, or deployment validation.

## Deliberate exclusions

The release excludes original construction images, image-derived overlays,
per-image labels and expert responses, detector weights, prediction caches,
redaction coordinates, and other restricted inputs. The image data remain
subject to organization confidentiality and privacy controls. The MIT license
applies to original repository code only and grants no rights to those data.
