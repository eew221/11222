# v0.4.5

This superseding archival release corrects the Zenodo identifier in the prior
release metadata and freezes the final 38-reference manuscript v38 package.
It includes MIT-licensed experiment code, public non-image analysis artifacts,
audit protocols, reproducibility documentation, and manuscript source.

Original construction-scene images, per-image labels, detector weights,
prediction caches, and image-derived overlays are deliberately excluded because
they remain subject to confidentiality and privacy controls.

The immutable GitHub tag identifies the archived commit. Zenodo creates a
version-specific DOI for this release under concept DOI
`10.5281/zenodo.22119277`.
