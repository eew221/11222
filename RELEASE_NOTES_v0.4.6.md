# v0.4.6 release notes

This immutable release freezes the v38 manuscript source, bibliography, public
non-image analysis artifacts, audit protocols, and reproducibility metadata used
for the accompanying submission package.

The release supersedes v0.4.5 without modifying that historical tag. The local
compiled manuscript PDF is tracked by the SHA-256 record in
`REPRODUCIBILITY.md`; the PDF is supplied separately as a release asset when
publication of the redacted qualitative figure is permitted.

The self-collected construction-scene images, per-image labels, detector
weights, prediction caches, and image-derived overlays remain excluded because
they are restricted by confidentiality and privacy controls.

Zenodo archives this tag as a version under concept DOI
`10.5281/zenodo.22119277`; the version record identifies `v0.4.6`.
